# NexLogin (`local_nexlogin`)

Dark centered login card for Moodle **login** and **signup** pages (circuit corners, field icons, blue Login CTA). Works **alongside Edwiser RemUI**.

## Install

1. Upload `nexlogin.zip` → Site administration → Plugins → Install plugins  
   (or unzip into `{moodle}/local/nexlogin/`)
2. Visit notifications to finish install
3. Purge all caches
4. Open `/login/index.php` or `/login/signup.php`

## Settings

**Site administration → Plugins → Local plugins → NexLogin**

- Enable / disable the custom UI
- Brand name (default: Nex Academy)

## Notes

- Moodle’s real login / signup forms are relocated into the left panel — authentication still runs through core.
- Hero image: `pix/hero.jpg` (replace anytime and purge caches).
