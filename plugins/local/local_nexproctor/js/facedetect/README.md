NexProctor ships pico.js (MIT) and the pico "facefinder" cascade for client-side face detection.

- pico.js: https://github.com/nenadmarkus/picojs (MIT)
- facefinder cascade: https://github.com/nenadmarkus/pico (from rnt/cascades/facefinder)

All face processing runs in the browser; images are not sent to a third-party service.
